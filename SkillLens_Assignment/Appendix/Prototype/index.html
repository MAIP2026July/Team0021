SkillLens
Prototype. Scoring is scripted (no live model). Quotations come from the response; confidence comes from how the response matches the rubric. All learners, responses and report values are synthetic. Not a validated assessment.
What this prototype does not prove
  • Scoring accuracy: no live model is used and no reference set has been scored.
  • Confidence: the three-run agreement rule is not implemented; low-confidence results are held only when a learner requests review.
  • Coverage: three scenarios per live skill area; three skill areas are coming soon.
  • Learning effect and fairness: not tested.
  • Integration: the API and CSV/JSON exports are downloadable files, not a live partner connection.

Development guidance, not a performance rating.
