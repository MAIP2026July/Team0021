SkillLens
Prototype. Scoring is scripted (no live model): quotations are taken from the response, and confidence is based on how strongly the response matches the rubric. Content is synthetic. This is not a validated assessment.
What this prototype does not prove
  • Scoring accuracy: no reference set has been scored by a live model.
  • Confidence routing: the three-run agreement rule is not implemented, and the automatic low-confidence route is not triggered. The reviewer queue fills only when a learner requests review.
  • Coverage: two scenarios per skill, against six for Python in the MVP.
  • Learning effect: a follow-up score change does not show improvement at work.
  • Integration: standalone; not connected to Skillsoft Percipio or to learner data.
  • Fairness: writing style and language groups have not been tested.
